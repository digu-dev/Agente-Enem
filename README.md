# Agente-Enem

Plataforma que resolve questões do ENEM, gera questões no estilo da prova,
monta simulados e produz relatórios de áreas para estudo.

O repositório inicia com um walking skeleton em Azure: aplicações React,
Spring Boot e Go, infraestrutura Terraform e entrega automatizada por GitHub
Actions usando OIDC.

Consulte [Fase 0 — walking skeleton](docs/FASE-0-WALKING-SKELETON.md) para
arquitetura, pré-requisitos de Azure/GitHub, bootstrap do state, pipeline,
testes e riscos conhecidos. Para ligar tudo à Azure, siga
[Como conectar com a Azure](docs/COMO-CONECTAR-COM-AZURE.md).
